MAIN INTERFACE

主界面：一目了然

整个主界面由三个区域组成：顶栏胶囊（时钟+进度+天气）、作业卡片网格、底栏胶囊（日期+学科+更多）。背景图自动从云端拉取缓存，玻璃拟态浮层悬浮其上。

① 顶栏胶囊

时钟（2rem 加粗）+ 晚修进度条（三节次自动追踪）+ 天气胶囊（emoji+温度+描述）。整个胶囊可拖拽移动窗口。

② 卡片网格

瀑布流 2~3 列自适应。每张卡片以学科色整体追色（30% 浓度玻璃底 + 学科色标题/圆点），玻璃拟态背景，hover 上浮 3px。点击卡片进入操作态。

③ 底栏胶囊

日期按钮（可前后翻页）+ 学科胶囊横滑列表（点击切换/添加作业）+ 更多功能按钮（上滑菜单）。

④ 背景图层

云端壁纸自动拉取缓存，12 张上限 LRU 淘汰。魔数校验图片格式，20MB 上限。断网保留缓存图。

FAQ

常见问题

作业数据存储在哪里？
数据以加密 JSON 文件存储在本机 userData 目录（AES-256-GCM 透明加密，密钥由 Windows 凭据保护 / DPAPI，可在设置 → 数据管理中开启或关闭）。归档数据同为本地 JSON 文件。可通过设置 → 数据管理导出备份。
QQ 自动捕获功能需要什么条件？
需要 Windows 10+ 系统，已安装 QQ 客户端，并在系统通知设置中允许 QQ 显示通知。首次使用需在设置 → QQ监听中添加老师名单（QQ 昵称 + 学科）。软件会启动 C# sidecar 子进程监听 Windows 通知中心。
天气数据不显示怎么办？
默认使用 Open-Meteo 免费 API（无需密钥）。如果无法获取数据，检查网络连接。如需更精准的本地天气和预警功能，可在设置中切换到和风天气数据源并填入 API Key。
背景图不更新了？
背景图从云端拉取，默认前台刷新模式（仅窗口可见时刷新）。如果网络断开，会保留上次缓存的图片。可在设置中切换背景图源（Upx8 / XXAPI）或调整刷新间隔。最多缓存 12 张图。
卡片上的圆圈编号怎么来的？
在添加/编辑弹窗中开启"自动编号"后，回车会自动续写序号（1. → 2. → 3.）。保存后卡片显示时，"1. " 格式会自动美化为圆圈编号（①），颜色与学科色一致。可在设置中关闭圆圈美化。
软件关闭后还在后台运行吗？
如果开启了系统托盘功能（默认开启），点击关闭按钮会最小化到系统托盘而非退出。QQ 监听功能需要后台运行才能工作。可在设置中关闭托盘功能，或在托盘菜单中选择"退出"完全关闭。
什么是画中画浮窗？
更多菜单 → 浮窗：选中的作业卡片会变成一个独立的置顶小窗，贴在屏幕右侧，可拖动、贴边吸附成探头，不打断你其他操作；退出浮窗模式后主窗口自动恢复。浮窗中正在显示的卡片不会在主窗口网格里重复出现。
如何自定义学科和颜色？
设置 → 学科管理，可以添加新学科、删除已有学科、修改学科颜色。颜色选择器提供 5 套预设色板（30 种颜色）和自定义 HEX 输入。修改后全局生效，包括卡片色条、底栏胶囊、圆圈编号等。
